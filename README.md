## Abstract

This project focuses on the design and simulation of a 4-bit binary arithmetic calculator using digital logic concepts. The system accepts 4-bit binary inputs and performs the arithmetic operations implemented in the circuit. The circuit is designed and tested using Logisim.

## Objectives

- Design a 4-bit binary arithmetic calculator.
- Implement the required arithmetic operations using digital logic.
- Simulate the circuit using Logisim.
- Test and verify the output for different input combinations.

## Tools Used

- Logisim
- Digital Logic Design

## Repository Structure

- `src/` - Circuit implementation
- `docs/` - Presentation and documentation
- `data/` - Supporting data and test cases
- `results/` - Simulation results
- `reports/` - Project reports

## Setup and Execution

1. Open the `.circ` file in Logisim.
2. Provide the required 4-bit inputs.
3. Select the required operation.
4. Run the simulation.
5. Observe and verify the output.
